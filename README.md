# TaskFlow – Team Collaboration System

TaskFlow is a full-stack MERN application developed for efficient team collaboration and task management. The application enables users to manage tasks, monitor progress, and organize workflows through a clean and responsive interface.

## Features

- User Authentication using JWT
- Task Creation, Update, and Deletion
- Task Status Management
- Dashboard with Task Statistics
- Search and Filter Functionality
- Team and Projects Management Pages
- Responsive User Interface
- Cloud Database Integration with MongoDB Atlas

## Technology Stack

### Frontend
- React.js
- React Router DOM
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JSON Web Token (JWT)

## Deployment

- Frontend hosted on Netlify
- Backend hosted on Railway
- Database hosted on MongoDB Atlas
